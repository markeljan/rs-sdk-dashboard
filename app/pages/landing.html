Set up the RS-SDK Dashboard (https://github.com/markeljan/rs-sdk-dashboard) locally for my rs-sdk bots:
1. Make sure Bun is installed (curl -fsSL https://bun.sh/install | bash).
2. Find my rs-sdk checkout (the folder with bots/<name>/bot.env). If there isn't one, clone https://github.com/MaxBittker/rs-sdk.git, run bun install, and create a bot with bun bots/create-bot.ts <name>.
3. Clone https://github.com/markeljan/rs-sdk-dashboard.git next to it and run bun install in it.
4. Start it so that it keeps running: RS_SDK_DIR=<path to rs-sdk> bun start. Check http://localhost:4747/_rsd/health. If other people share this network, set RSD_PASSWORD.
5. Only one game client can be logged in per account. For accounts with no client running anywhere else, let the dashboard run it: curl -X PATCH http://localhost:4747/_rsd/api/accounts/<name> -H 'content-type: application/json' -d '{"runClient":true}'. New characters need await bot.skipTutorial() once.
6. Tell me the URL for this computer and the "Phone (same Wi-Fi)" URL it printed.
